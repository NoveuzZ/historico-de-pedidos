# 📜 Histórico de Pedidos

Sistema de consulta e busca inteligente para pedidos realizados na Lanchonete Express.

## 📝 Descrição
Este programa permite que o usuário acesse seu histórico pessoal de compras. Após o login, o sistema lê o arquivo específico do usuário (`pedidos_usuario.txt`) e oferece ferramentas de busca para filtrar pedidos por itens específicos ou por forma de pagamento.

## 🎯 Objetivo
Praticar a leitura de arquivos linha por linha, uso de filtros de busca com o operador `in` e organização de dados para exibição ao usuário final.

## 🚀 Como executar
1. Execute o arquivo:
   ```bash
   python historico_pedidos.py
   ```
2. O sistema buscará automaticamente o arquivo de pedidos correspondente ao usuário logado.

## 🛠️ Tecnologias usadas
- **Python 3**
- **Filtros de Busca** (Lógica de pesquisa em strings)
- **Persistência de Dados** (Leitura de arquivos TXT)
